# Bug 01 – Salary Structure Form Repeater Broken (Fixed 03-10-25)

## Summary
- **Module:** Payroll → Salary Structures (create / edit forms)
- **Symptom:** “Add Component” button did nothing; Playwright spec could not find `.list-group-item`
- **Console Errors:** `salaryStructureForm is not defined`, `componentRepeater is not defined`, `Unexpected token '}'`
- **Root Cause:** Alpine helper functions were removed from the bundle, leaving `x-data` references unresolved. Raw JSON interpolated into the `x-data` attribute also produced malformed expressions.

## Diagnosis
- UI never instantiated Alpine data → `.list-group-item` never rendered.
- Manual inspection showed `salaryStructureForm()` and `componentRepeater()` undefined.
- JSON with quotes injected into `x-data` caused syntax errors (`Unexpected token '}'`).

## Fix
1. Reintroduced helpers in `resources/js/app.js`:
   - Registered `salaryStructureForm` and `componentRepeater` via `Alpine.data`.
   - Added UUID fallbacks, group/row normalisation, and safe submit handling.
2. Ensured `@vite('resources/js/app.js')` loads in `layouts/app.blade.php`.
3. Updated Blade templates (`salary-structures/create.blade.php`, `salary-structures/edit.blade.php`):
   - `x-data="salaryStructureForm()"` and `componentRepeater(@js(...))`.
   - Marked repeater section with `data-salary-structure-repeater`.
4. Added Playwright regression test `tests/playwright/salary-structures.spec.ts` to cover multi-component creation.
5. Rebuilt assets (`npm run build`) and confirmed Playwright spec passes.

## Verification
- `npx playwright test tests/playwright/salary-structures.spec.ts --project=chromium`
- Manual UI smoke test: Add Component → new row appears and form submits.
